# Environment Setup
Install [Mamba](https://mamba.readthedocs.io/en/latest/installation/mamba-installation.html) to manage environments.  
  
Setup environments:  
```
mamba create -f nemo.yaml
mamba create -f nemo_cpu.yaml
mamba create -f prep.yaml
```
